# 🎓 بوابة استعلام أكواد وكارنيهات الطلاب - جامعة اللوتس بالمنيا (LUM)
### تصميم وإشراف: م / بولس سمير - مدير شئون الطلاب

---

## 🌟 نظرة عامة على النظام
تم تصميم هذا النظام المتكامل كمنصة ويب حديثة بنظام **Single Page Application (SPA)** تعمل بتقنيات:
- **HTML5 & CSS3** مع نظام تصميم مخصص (Custom Dark Theme) ومؤثرات زجاجية (Glassmorphism).
- **Bootstrap 5 (RTL)** لتوافق كامل مع الشاشات والهواتف الذكية.
- **JavaScript (ES6+)** النقي بدون أي تعقيدات.
- **SheetJS (xlsx)** لتحليل ملفات الإكسيل ورفعها وقراءتها محلياً وفورياً داخل المتصفح.
- **JsBarcode** لتوليد باركود رسمي عالي الدقة لكل طالب قابل للطباعة على الكارنيه.
- **Firebase Realtime Database** لمزامنة وتخزين بيانات الطلاب سحابياً فورياً.

## ✨ المميزات والخصائص المطبقة

### 1. واجهة استعلام الطالب (User Interface):
- **البحث بالرقم القومي**: يدعم إدخال الـ 14 رقماً بالأرقام الإنجليزية أو العربية، مع إزالة أي مسافات أو رموز تلقائياً.
- **عرض تفاصيل الطالب**:
  - اسم الطالب رباعي.
  - الرقم القومي.
  - الفرقة الدراسية.
  - اليوم المقرر لاستلام الكارنيه.
  - المكان أو القاعة المحددة.
- **تمييز الكود الجامعي والسهم المتحرك (ميزة خاصة)**:
  - ينقسم الكود إلى **جزء ثابت** (مثل بادئة الجامعة `LUM-`) و **جزء مميز ملون وجذاب** بألوان النيون المتوهجة.
  - **سهم متحرك ونشط (Animated Bouncing Arrow)** يشير مباشرة إلى الجزء المميز الصغير ومكتوب عليه: `👈 هذا هو الكود`.
  - زر لنسخ الكود بلمسة واحدة.
  - **باركود حي ومباشر** خاص بكل طالب للكارنيهات.
  - زر لطباعة إشعار وبيانات الطالب أو نسخها.

### 2. واجهة الإدارة وشؤون الطلاب (Admin Interface):
- **حماية برقم سري (PIN Code)**: لمنع وصول الطلاب لشاشة التعديل (الرقم الافتراضي: `1234` أو `admin123`).
- **رفع ملفات الإكسيل (Excel Upload)**:
  - دعم صيغ `.xlsx` و `.xls` و `.csv`.
  - خاصية السحب والإفلات (Drag & Drop) أو التصفح.
  - **التعرف التلقائي الذكي على الأعمدة العربية والإنجليزية**:
    - `الرقم القومي` / `National ID`
    - `الاسم` / `اسم الطالب` / `Name`
    - `الكود` / `كود الطالب` / `Code`
    - `الفرقة` / `Grade`
    - `اليوم` / `Day`
    - `المكان` / `Location`
  - زر تنزيل **نموذج إكسيل تجريبي** جاهز.
- **المزامنة السحابية مع Firebase**:
  - رفع وتحديث مئات أو آلاف الطلاب دفعة واحدة (Batch Update) مع شريط نسبة تقدم (Progress Bar).
- **إدارة السجلات وتصديرها**:
  - جدول تفاعلي مباشر يعرض كافة الطلاب المسجلين.
  - بحث وتصفية فورية في الجدول.
  - إمكانية حذف طالب محدد أو تفريغ قاعدة البيانات.
  - تصدير كامل البيانات الحالية إلى ملف إكسيل جديد بضغطة زر.
- **لوحة تخصيص تقسيم الكود**:
  - اختيار طريقة تقسيم الكود (آخر 4 أرقام، آخر 3 أرقام، آخر 5 أرقام، أو حسب الفواصل `-` و `/`).
  - تعديل نص السهم المتحرك والبادئة مع معاينة حية فورية.

### 3. الهوية البصرية وشعار الجامعة:
- **الشعار الرسمي لجامعة اللوتس بالمنيا (LUM)** بدون خلفية بيضاء بتقنية Vector شفافة متناسقة تماماً مع الوضع الداكن.
- **وضع داكن فخم (Dark Mode)** بألوان كحلية عميقة مع لمسات السيان والذهبي والأخضر.
- **توقيع مدير شئون الطلاب**:
  - `تصميم مهندس / بولس سمير - مدير شئون الطلاب` في أسفل الواجهة بشكل رسمي وأنيق.

## 🚀 كيفية تشغيل واستخدام المشروع

1. قم بفتح مجلد المشروع:
   `باركود طلاب للكارنيهات`
2. افتح ملف `index.html` مباشرة بالنقر المزدوج في أي متصفح (Google Chrome، Microsoft Edge، Firefox، أو المتصفح على الهاتف).
3. **للدخول إلى لوحة الإدارة**:
   - اضغط على زر **لوحة الإدارة** في أعلى اليسار.
   - أدخل الرقم السري: `1234` واضغط فتح.
   - يمكنك الآن سحب وإفلات أي ملف إكسيل لديك ثم الضغط على **حفظ ومزامنة بالفيربيس**.

## 🔒 ملاحظة هامة بخصوص قواعد حماية Firebase (Security Rules):
للتأكد من أن تطبيق الويب يستطيع القراءة والكتابة في الـ Realtime Database بدون أخطاء صلاحيات، تأكد من ضبط قواعد Firebase Realtime Database من لوحة تحكم Firebase Console كالتالي:

```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```

> **ملاحظة**: رابط قاعدة البيانات المربوطة في المشروع هو:
> `https://bolestest-default-rtdb.firebaseio.com`
